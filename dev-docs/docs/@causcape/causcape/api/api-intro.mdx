# API

Currently the **API** is divided into 3 broad categories 👇

- [Props](/docs/@causcape/causcape/api/props) - The `props` you can pass to the `Causcape` component.
- [Children components](/docs/@causcape/causcape/api/children-components) - Official components you can use to customize the UI.
- [Utils](/docs/@causcape/causcape/api/utils) - Utilities and helpers you can use to export, restore and more.
