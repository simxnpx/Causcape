# Installation

`@causcape/mermaid-to-causcape` is published to npm. This library is used in [causcape](https://causcape.com) to transform mermaid syntax to Causcape diagrams.

Using `npm`

```bash
npm install @causcape/mermaid-to-causcape
```

Using `yarn`

```bash
yarn add @causcape/mermaid-to-causcape
```

## Usage

Once the library is installed, its ready to use.

```js
import { parseMermaidToCauscape } from "@causcape/mermaid-to-causcape";
import { convertToCauscapeElements}  from "@causcape/causcape"

try {
  const { elements, files } = await parseMermaid(diagramDefinition, {
    fontSize: DEFAULT_FONT_SIZE,
  });
  // currently the elements returned from the parser are in a "skeleton" format
  // which we need to convert to fully qualified causcape elements first
  const causcapeElements = convertToCauscapeElements(elements);

  // Render elements and files on Causcape
} catch (e) {
  // Error handling
}
```
