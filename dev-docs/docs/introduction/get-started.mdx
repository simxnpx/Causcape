Go to [causcape.com](https://causcape.com) to start sketching.

## How are these docs structured

These docs are focused on developers, and structured in the following way:

- [Introduction](/docs/) — development setup and introduction.
- [@causcape/causcape](/docs/@causcape/causcape/installation) — docs for the npm package to help you integrate Causcape into your own app.
- Editor — IN PROGRESS. Docs describing the internals of the Causcape editor to help in contributing to the codebase.
- [@causcape/mermaid-to-causcape](/docs/@causcape/mermaid-to-causcape/installation) - Docs for the mermaid to causcape parser
